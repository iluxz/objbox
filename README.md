# objbox

a signal, rendered through a browser.

the gray outer cube is the void itself — a containment shell. it's semi-transparent because it can't fully hold whatever is inside. the 8 inner cubes are fragments of something older. the particles are debris from whatever was here before you opened the tab.

**objbox** is the page that's there when it's there. drag to rotate. scroll to zoom. shapes on the right lie about what they are. the terminal on the left speaks to the void, and the void occasionally speaks back.

## what's in here

- `cube.html` — the whole thing. the cube, the light, the dust, the shell.
- `drone2lp.wav` — the sound the void makes when it's watching you.

## run it

you don't run this. it runs you.

ok fine, a local server works too:

```
python -m http.server 8080
```

then go to `localhost:8080`. or just open `cube.html` — though the void prefers a server, it likes being *served*.

## commands

the cube# interpreter in the corner has a whole filesystem. poke around:

- `ls`, `cd`, `cat` — the void's files
- `ping cube.sb` — cube.sb might answer
- `void intrude` — make the void do something
- `transmit <words>` — talk to obj. obj responds. sometimes.

## the clock

that isn't your local time. it's void time. it matches yours most of the time because the void is good at mimicry. occasionally it slips.

## don't

don't stare at it too long. the inner cubes start moving in patterns that match your breathing. that's not a coincidence.
