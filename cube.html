voidscript command reference
output
print <text> — print text to output
say <text> — say something (with delay)
warn <text> — print a warning
error <text> — print an error
timing
wait <ms> — pause execution (milliseconds)
sleep <ms> — alias for wait
system
theme <1-5> — switch color theme
glitch — trigger glitch effect
shape <name> — change shape (cube/sphere/tetra/cyl)
bgm — toggle background music (wed: furnace, fri: landscaping)
clear — clear the output log
travel <zone> — travel through the void
logic
loop <n> — repeat block n times (close with endloop)
loop counts are capped at 100 iterations for browser safety
endloop — close loop block
if <condition> — conditional block (close with endif)
else — run the alternate branch when the if is false
endif — close if block
break — leave the current loop
continue — jump to the next loop iteration
fn name args ... endfn — define a reusable function
macro name args ... endmacro — define a reusable macro
call name args — invoke a function or macro
return — stop the current script
random name min max — store a random integer
assert name value — stop when a variable does not match
calc <expr> — evaluate math (e.g. calc 2+2)
set <var> <val> — set a variable
get <var> — get a variable value
if conditions
if x == 5 — equals
if x != 0 — not equals
if x > 10 — greater than
if x < 5 — less than
if x >= 1 — greater or equal
if x <= 100 — less or equal
if myvar — truthy (exists, not 0/false/empty)
conditions are case-sensitive. strings must match exactly.
example: set count 3 — if count == 3 — print yes — endif
variables expand with $name or ${name}; missing variables become empty text.
function example: fn greet name / say hello $name / endfn / call greet intruder
definitions are collected before execution, so functions may be written anywhere.
gui — create windows
gui window "title" <w> <h> [random] — create window
gui taskbar "title" [h] — full-width bottom taskbar
gui clear — close every generated GUI window
gui label "text" <x> <y> — add a label
gui button "text" <x> <y> "cmd" — add button
gui input "placeholder" <x> <y> — add text input
gui check "label" <x> <y> — add checkbox
gui image "url" <x> <y> [w] [h] — add image
gui close — close active window
slider <min> <max> <value> <var> — add a range slider
dropdown <var> "opt1,opt2,..." <default> — add a dropdown select
colorpicker <var> "#hex" — add a color picker
filesystem
cat <path> — read file
ls [path] — list directory
pwd — current directory
cd <path> — change directory
touch <name> — create file
mkdir <name> — create directory
echo > <file> — write to file
rm <path> — remove file
cp <source> <destination> — copy a file
mv <source> <destination> — move or rename a file
tree [path] — show the virtual filesystem tree
variables
set <name> <value> — store a variable
var <name> <value> — store a variable (alias)
get <name> — recall a variable
admin
admin <passphrase> — unlock admin mode (bypasses safety limits)
alwaysontop <on|off> — make active window stay on top of everything
godmode <on|off> — make the cube invulnerable
speed <0.1-10> — change script execution speed
broadcast <text> — send a transmission across all zones
debug — show internal state (vars, windows, zone, memory)
freeze <on|off> — freeze the cube in place
noclip <on|off> — drag windows anywhere, even offscreen
override theme <1-8> — access hidden themes
setday <0-6|mon-sun|reset> — override the day (test wednesday music, etc)
eval <code> — run raw javascript (dangerous)
relay <url> [sender-id] — connect to broadcast relay
unlisten — stop receiving broadcasts
danger list — view available advanced scripts
danger run <name> — launch a danger zone script
tips
one command per line. commands are case-sensitive.
use quotes around strings with spaces.
loop/endloop and if/endif must be on their own lines.
if conditions: if x == 5, if x != 0, if x > 10, if x < 5
if conditions: if x >= 1, if x <= 100, if myvar (truthy check)
gui commands create elements in the preview panel.
disable PREVIEW before running GUI-heavy scripts to avoid creating preview windows.
safety limits: 100 iterations per loop, 100 GUI windows, 10000 script operations.
press Ctrl+Enter to run. Ctrl+S to save. Esc to exit.
