logic
loop <n> — repeat block n times (close with endloop)
loop counts are capped at 100 iterations for browser safety
endloop — close loop block
if <condition> — conditional block (close with endif)
else — run the alternate branch when the if is false
endif — close if block
break — leave the current loop
continue — jump to the next loop iteration
fn name args ... endfn — define a reusable function
macro name args ... endmacro — define a reusable macro
call name args — invoke a function or macro
return — stop the current script
random name min max — store a random integer
assert name value — stop when a variable does not match
calc <expr> — evaluate math (e.g. calc 2+2)
set <var> <val> — set a variable
get <var> — get a variable value
if conditions
if x == 5 — equals
if x != 0 — not equals
if x > 10 — greater than
if x < 5 — less than
if x >= 1 — greater or equal
if x <= 100 — less or equal
if myvar — truthy (exists, not 0/false/empty)
conditions are case-sensitive. strings must match exactly.
example: set count 3 — if count == 3 — print yes — endif
variables expand with $name or ${name}; missing variables become empty text.
function example: fn greet name / say hello $name / endfn / call greet intruder
definitions are collected before execution, so functions may be written anywhere.

tips
one command per line. commands are case-sensitive.
use quotes around strings with spaces.
loop/endloop and if/endif must be on their own lines.
if conditions: if x == 5, if x != 0, if x > 10, if x < 5
if conditions: if x >= 1, if x <= 100, if myvar (truthy check)
gui commands create elements in the preview panel.
disable PREVIEW before running GUI-heavy scripts to avoid creating preview windows.
safety limits: 100 iterations per loop, 100 GUI windows, 10000 script operations.
press Ctrl+Enter to run. Ctrl+S to save. Esc to exit.
